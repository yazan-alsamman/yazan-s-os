# Acceptance Criteria

## Global

-   [ ] Authentication works.
-   [ ] User isolation is enforced.
-   [ ] All core entities have validation.
-   [ ] Database migrations are deterministic.
-   [ ] CI runs lint/typecheck/tests/build.
-   [ ] Errors are observable.
-   [ ] UI supports light/dark mode.
-   [ ] Responsive layout works.
-   [ ] WCAG 2.2 AA principles are followed.

------------------------------------------------------------------------

## Command Center

-   [ ] KPIs load from real persisted data.
-   [ ] KPI definitions are discoverable.
-   [ ] Every KPI supports drill-down.
-   [ ] Charts have date ranges.
-   [ ] Charts have accessible alternatives.
-   [ ] AI insights show evidence.
