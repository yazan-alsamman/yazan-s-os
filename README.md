## Build Philosophy

This is intended to be built as a serious production product, not a
dashboard mockup.

The target quality bar includes: - premium UX - deep analytics -
structured professional knowledge - strong data model - evidence-based
career intelligence - AI grounded in first-party data - production
security - observability - accessibility - responsive design - automated
testing

## Recommended first command

After placing these files in the repository, instruct Claude Code to
read all specification files before writing application code and then
execute Phase 0 from `08_IMPLEMENTATION_PHASES.md`.

## Important

Personal facts should be imported/reviewed rather than hard-coded. The
website/profile importer is part of the system design.
